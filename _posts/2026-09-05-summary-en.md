## [NVIDIA Releases PAIR Software to Turn Idle Home PCs into Local AI Clusters](https://www.techspot.com/news/113742-nvidia-pair-software-turns-idle-home-computers-local.html) ⭐️ 8.0/10

NVIDIA has released PAIR (Personal AI Router), a free, open-source beta software that connects idle home computers equipped with GeForce RTX GPUs, DGX Spark, and Macs into a unified local AI cluster without requiring dedicated cables. The software supports popular inference backends such as Ollama and LM Studio, and can be set up in minutes over an existing home network. PAIR democratizes distributed AI inference by allowing ordinary households to aggregate approximately 165 teraFLOPS of idle compute power into a privacy-preserving local cluster without specialized infrastructure. This is significant for the local AI ecosystem because it lowers the barrier to running large models locally, keeping data entirely on the user's network while maximizing the utility of hardware they already own. PAIR operates in beta and routes inference tasks across devices already present on the same local network, with no dedicated cabling required. It integrates with Ollama and LM Studio as inference backends, both of which rely on the llama.cpp engine lineage, and all data and queries remain confined to the local network.

**Background**: Local AI inference has grown rapidly with tools like Ollama and LM Studio, which allow users to run large language models on consumer hardware using the llama.cpp engine. NVIDIA's DGX Spark is a personal AI supercomputer powered by the GB10 Superchip, designed for desktop AI workloads with unified memory architecture. PAIR builds on this trend by addressing the fragmentation problem: most households have multiple capable devices sitting idle, but no easy way to combine their compute power for a single AI task.
